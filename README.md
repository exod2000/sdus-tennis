## Installation
Sauvegardez votre ancien dossier, puis copiez le contenu de `sdus-tennis` dans votre projet existant. Dans PowerShell : `npm.cmd install` puis `npm.cmd run dev`.

Le bouton « Contacter le club » ouvre la page Contact avec téléphone et e-mail. Les fiches PDF sont incluses.
